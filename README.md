# Arslan Shah — Premium Static Portfolio

Simple HTML/CSS/JavaScript version of the portfolio. No Node.js, Next.js, React, database or build step required.

## Run
Open `index.html` directly in a browser, or use any static server.

## Structure
- `index.html`
- `css/style.css`
- `js/script.js`

The accent is a bright light blue/cyan instead of the previous yellow/lime theme. Project content is stored in `js/script.js` for easy editing.
